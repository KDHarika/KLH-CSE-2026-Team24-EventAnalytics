## Abstract
The University Event Analytics System is a comprehensive tool that facilitates the gathering, processing, and visualization of various types of data pertaining to events held on campus, such as attendance and behavioral or feedback data. Currently, this information is spread across different departments and systems, making collection and analysis difficult. With automated registration, automatic attendance counting via QR codes and RFID (Radio Frequency Identification) tags, and visual dashboards, administrators, faculty, and student organizers gain the insights they need. The system uses Artificial Intelligence to assist in planning future events using historical data and forecasting attendance for better distribution of venues and resources. It also employs AI-based sentiment analysis of feedback to measure student satisfaction, automatically identifying what works and what doesn't, so that lessons from each event directly inform the planning of the next. The system is designed to be scalable and versatile, allowing integration with existing university management systems such as LMS.
